# Asal proyek

## Sumber awal

[Arroyan23/MCP-Kampus](https://github.com/Arroyan23/MCP-Kampus), ditemukan melalui [Glama](https://glama.ai/mcp/servers/Arroyan23/MCP-Kampus), adalah basis implementasi. Snapshot awal lokal: `6e74905d4d95d984586029dc630f1b0198c5bd40`, commit penulis Oyeng pada 15 September 2026. README upstream menyatakan MIT; snapshot tersebut tidak memuat berkas LICENSE terpisah.

Versi awal menyediakan empat tool untuk status, dashboard, kelas, dan tautan aktivitas melalui MCP lokal. Pengembangan lanjutan menambahkan reader terstruktur, Keychain, pengikatan akun, pemulihan sesi, prioritas, riwayat, pembacaan detail, resolver materi, penggunaan ulang file, helper, skill, serta pengujian.
