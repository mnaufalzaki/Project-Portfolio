## Overview

This folder contains the programmatic video source code and the latest rendered output (`output/ZSharia_Teaser_SYLS2026_v2.mp4`) for the **Z-Sharia** SYLS 2026 teaser. Instead of keyframing manually in a traditional NLE, all animations, UI phone mockups, spring physics, and frame-locked sound cues are written deterministically in React/TypeScript with **Remotion**, paired with original synthesized music (120 BPM, C major) and 6 sound effects generated by `audio/make_audio.py`.

## Design System Constraints

- **Palette:** Primary Teal `#43AEA4`, Dark Teal `#1F7068` (text), Soft Teal `#E3F4F2` (surface), Ink `#26302F`, Gold `#F7AE49` (reserved strictly for XP coins, streak flames, chests, trophies, mascot collar coin, and brand hyphen).
- **Typography:** Local Nunito (`600`, `800`, `900` + italic), rounded geometry with solid bottom-edge depth.
- **Mascot rule:** The cat mascot is never placed directly on `#43AEA4` teal; on the closing logo card it sits on a white tile.
- **Audio mastering:** `-18.3 LUFS` integrated loudness, `-1.4 dBFS` true peak, clean silent tail.

## Running & Rendering Locally

```bash
cd Z-Sharia/teaser
npm install
npm run audio          # Optional: regenerate music + SFX into public/audio/*.wav
npx remotion studio    # Live preview (composition: "ZSharia-Teaser")
npm run render         # Render MP4 via Remotion
npm run export:svg     # Optional: export character & reward SVGs
```

If Remotion cannot download headless Chrome, point to a local Chromium binary:

```bash
REMOTION_CHROME=/path/to/chrome npm run render
```
